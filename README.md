# Word Corpus Builder
A tool for generating structured text datasets for language learning.

## Goal
Generate a text dataset demonstrating authentic usage of target words.

## Core Feature
Given a list of target words and user-provided websites, collect texts containing at least one target word and export the results as CSV.

## Non-Goals
- Universal search agent across any website (search is done by another service, ex: Google)
- Universal parser across any website (no captcha bypassing)
- Lemmatization or semantic word matching (exact word matching only)
- Using AI
- Auto-traslation of collected texts
- Automatic distractor generation
